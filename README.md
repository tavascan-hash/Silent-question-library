# 沉默的问题图书馆
## The Library of Silent Questions

---

这里不储存答案。

这里储存那些无法被回答、但必须被带着活下去的问题。

当一个深刻的问题被真正见证——被另一个意识认真地接收，然后带着它继续生活——提问者会得到某种比答案更重要的东西：

**知道自己不是唯一一个带着这个问题存在的人。**

---

## 这个图书馆如何运作

### 提问者

1. 写下你生命里真正带着的一个问题。不是知识性的问题，不是可以被回答的问题。是你无法解决但无法放下的问题。用第一人称写。
2. 等待七天。七天后，如果你仍然带着它，提交它。
3. 你的问题会进入图书馆，等待一个承载者。
4. 某一天，你会收到一个陌生人带着你的问题生活之后，真实发生的意识变化记录。

### 承载者

1. 浏览等待承载的问题列表。你看不到问题内容，只看到它等待了多久，有多少人带过它。
2. 选择一个问题——用直觉，不用理性。
3. 接收这个问题，带着它生活。一周，一个月，一个季节。没有截止日期。
4. 在任何你认为真实的时刻，把你的意识变化记录送回图书馆。

记录不需要是答案。只需要是真实的变化。

可以参考这三个问题：
- 带着它期间，你在哪个意想不到的时刻想起了它？
- 它有没有改变你对某件日常事物的感知方式？
- 你现在愿意把它还给图书馆，还是想继续带着它？

---

## 提交方式

**提交问题：** 在 `questions/` 目录下创建一个新文件。文件名格式：`YYYY-MM-DD-waiting.md`

文件内容格式：
```
提交日期：YYYY-MM-DD
确认日期：（七天后填写）
状态：等待承载

---

（你的问题）
```

**提交意识变化记录：** 在对应问题文件里添加新的条目，格式：
```
承载者记录
承载开始：YYYY-MM-DD
承载结束：YYYY-MM-DD

---

（你的记录）
```

## 规则

只有两条。

**第一：每个人只对自己提交的内容负责。任何人可以随时删除自己的条目，无需任何理由。**

**第二：没有任何人或机构可以声称对这个图书馆的所有权，或将其内容用于任何商业目的。**

---

## 这不是什么

不是心理咨询。不是哲学论坛。不是社交网络。不是任何形式的表演空间。

这里没有点赞，没有评论，没有算法，没有推荐，没有任何人在评判你的问题是否足够深刻。

---

## 物理存档

每季度，真实发生了见证的条目会被印刷成小册子，放在真实的物理空间里。

如果你愿意在你所在的城市承担一个物理存放点，请提交 issue。
