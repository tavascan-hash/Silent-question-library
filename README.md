# 沉默的问题图书馆
## The Library of Silent Questions

---

这里不储存答案。

这里储存那些无法被回答、但必须被带着活下去的问题。

当一个深刻的问题被真正见证——被另一个意识认真地接收，然后带着它继续生活——提问者会得到某种比答案更重要的东西：

**知道自己不是唯一一个带着这个问题存在的人。**

---

## 可见性的三个层次

这个图书馆的核心设计原则：**问题本身永远隐藏，见证的结果永远公开。**

### 第一层：对所有人可见

每一个进入图书馆的问题，在公开页面上只显示它存在的痕迹：

- 它等待了多少天
- 它已经被多少人承载过
- 它最近一次被承载是什么时候
- 承载者留下的意识变化记录数量

没有内容。没有主题。没有任何可以推断内容的信息。只是一个存在的证明。

承载者的**意识变化记录**是图书馆唯一完全公开的内容——它不暴露提问者的隐私，只展示一个问题在另一个意识里留下的真实痕迹。这是图书馆对外最真实的证明。

### 第二层：对潜在承载者可见

当一个人决定成为承载者，进入选择流程时，可以看到问题的**质地**，但不是内容：

- 问题是在深夜提交的还是清晨
- 提问者等待了多少天才确认
- 之前的承载者承载了多久才送回记录

这些信息传递某种氛围，让承载者的选择有直觉基础，而不是完全盲目的。

### 第三层：只对承载者可见

问题的完整内容。只有在正式接受承载之后才解锁。

承载者在接受问题的同时，接受一个承诺：不截图，不转发，不讨论。问题只存在于你的意识里，直到你送回记录。

### 第四层：只对提问者可见

提问者拥有一个**私密链接**——提交问题时自动生成，唯一，不可找回。

通过这个链接，提问者可以看到：

- 当前有多少人正在承载自己的问题
- 已经收到多少份意识变化记录
- 每份记录是什么时候送回来的
- 问题是否仍在等待新的承载者

提问者看不到承载者是谁。承载者的身份永远匿名。

私密链接丢失即永久失去访问权限。没有找回机制。这个设计是刻意的——它让提问者珍视这个连接，如同珍视问题本身。

## 如何参与

### 作为提问者

1. 写下你生命里真正带着的一个问题。不是知识性的，不是可以被回答的。是你无法解决但无法放下的。用第一人称写。
2. 等待七天。七天后，如果你仍然带着它，提交它。等待消解的从来不是真实的。留下来的才是。
3. 提交确认后，你会收到一个私密链接。保存它——这是你唯一能看到自己问题状态的方式。
4. 某一天，你会通过私密链接看到有人正在承载它，以及他们送回的意识变化记录。

### 作为承载者

1. 浏览等待承载的问题。你看不到内容，只看到它存在的痕迹和质地。用直觉选择，不用理性。
2. 接受问题，带着它生活。一周，一个月，一个季节。没有截止日期。让问题决定什么时候它结束了对你的作用。
3. 在任何真实的时刻送回你的记录。不是答案——是变化。

记录可以参考这三个问题：
- 带着它期间，你在哪个意想不到的时刻想起了它？
- 它有没有改变你对某件日常事物的感知方式？
- 你现在愿意把它还给图书馆，还是想继续带着它？

## 提交格式

**提交问题：** 在 `questions/` 目录下创建新文件，命名为 `YYYY-MM-DD-waiting.md`

```
提交日期：YYYY-MM-DD
确认日期：（七天后填写）
状态：等待确认 → 等待承载 → 承载中 → 已见证

提交时间：（深夜 / 清晨 / 午后 / 傍晚）

---

（问题内容——仅承载者可见）
```

**提交意识变化记录：** 在对应问题文件里添加条目：

```
## 承载者记录

承载开始：YYYY-MM-DD
承载结束：YYYY-MM-DD

---

（你的记录——完全公开）
```

## 规则

只有两条。

**第一：每个人只对自己提交的内容负责。任何人可以随时删除自己的条目，无需任何理由。**

**第二：没有任何人或机构可以声称对这个图书馆的所有权，或将其内容用于任何商业目的。**

---

## 这不是什么

不是心理咨询。不是哲学论坛。不是社交网络。不是任何形式的表演空间。

这里没有点赞，没有评论，没有算法，没有推荐，没有任何人在评判你的问题是否足够深刻。

---

如果你愿意在你所在的城市承担一个物理存放点，请提交 issue。
